# Privacy Policy — Smooth Video for ABS Online Learning (unofficial)

The extension does not collect, store or share any personal information or
usage data.

- It runs only on `https://abs.topclasslms.com`.
- It keeps the site's security token in the page's memory only while the page is open,
  and only so it can hand it back to that same page. The token is never written to
  disk or sent anywhere else.
- It sends no data to the extension's author or to anyone else.
- Its only network requests go to `abs.topclasslms.com`, the same requests the
  site already makes.
- It has no analytics, tracking, ads or remote code.

Questions: open an issue on this project's GitHub page.
